# World Layoffs EDA using SQL

Exploratory Data Analysis (EDA) on a global layoffs dataset using SQL to identify trends, company-wise layoffs, industry impact, yearly patterns, and rolling monthly totals.

## Skills Used
- SQL
- Aggregate Functions
- GROUP BY
- CTEs
- Window Functions
- Date Functions
- Rolling Aggregations

## Key Analyses
- Top companies by layoffs
- Layoffs by country
- Layoffs by industry
- Yearly trends
- Monthly rolling totals
